## 1. 포트폴리오 HTML 열람 및 구동 방법

[포트폴리오.html](포트폴리오.html)은 별도의 웹 프레임워크나 설치 없이 브라우저에서 바로 열 수 있는 정적 웹페이지입니다. 시연 화면 캡처는 같은 폴더의 `images/`에서 불러오므로, **다른 곳에 옮기거나 공유할 때는 `포트폴리오.html`과 `images/` 폴더를 함께** 옮겨야 합니다.

### 방법 A. 파일 직접 실행 (가장 간편)
* **파일 탐색기**: `포트폴리오.html` 파일을 더블 클릭하여 기본 웹 브라우저로 엽니다.
* **터미널 (PowerShell)**:
  ```powershell
  Start-Process "포트폴리오.html"
  ```

### 방법 B. 로컬 정적 웹서버 서빙 (권장)
로컬 HTTP 웹서버를 띄워 접근하면 폰트 및 리소스 렌더링이 가장 안정적입니다:
```powershell
# 프로젝트 루트 디렉토리에서 실행
python -m http.server 8080
```
* 브라우저 주소창에 `http://localhost:8080/포트폴리오.html` 접속

### 방법 C. IDE Live Server 활용
* VS Code 또는 Antigravity IDE의 **Live Server** 확장을 사용하여 `포트폴리오.html`을 우클릭한 뒤 **Open with Live Server**를 선택합니다.

## 2. 포트폴리오 정상 구동을 위한 요구사항

| 항목 | 요구사항 및 권장 환경 | 비고 |
| :--- | :--- | :--- |
| **인터넷 연결** | 권장 (웹 폰트 로드용) | Google Fonts (Plus Jakarta Sans, JetBrains Mono, DM Serif Display) + jsDelivr (Pretendard). 오프라인이면 기본 폰트로 표시 |
| **웹 브라우저** | 최신 Chromium 기반 브라우저 (Chrome, Edge), Safari, Firefox | 최신 CSS 그리드, 폰트 및 블러 백드롭(`backdrop-filter`) 지원 필수 |
| **로컬 의존성** | `images/` 폴더 (시연 화면 캡처 17장, 약 640KB) | CSS·JS는 HTML 안에 포함. 이미지는 `포트폴리오용 사진/` 원본을 잘라 웹용으로 줄인 사본 |
| **해상도** | 반응형 지원 (데스크톱, 태블릿, 모바일) | 화면 크기에 맞춰 레이아웃 자동 최적화 |

## 3. PDF 백서(Whitepaper) 인쇄 및 추출 방법

포트폴리오 우측 상단의 **`🖨️ PDF 인쇄`** 버튼을 누르거나 `Ctrl + P` (Mac: `Cmd + P`)를 누르면 인쇄용 CSS(`@media print`)가 자동으로 적용됩니다.

* **배경 그래픽 포함**: 인쇄 옵션에서 **'배경 그래픽(Background graphics)'**을 체크합니다.
* **여백(Margins)**: '기본(Default)' 또는 '없음(None)'으로 설정합니다.
* **레이아웃**: '세로(Portrait)' 선택 시 깔끔한 흰색 배경의 공식 기술 백서 문서로 저장됩니다.

## 4. Style.ai 전체 프로젝트 구동을 위한 필수 파일 목록

포트폴리오에 기술된 실제 AI 패션 추천 및 가상 피팅 시스템을 구동하려면 아래 핵심 파일들이 준비되어 있어야 합니다.

### 1) 환경 변수 및 의존성
* [`.env`](../.env.example) : 외부 API 키 설정
  * `OPENAI_API_KEY`: GPT-4o 도슨트 및 스타일리스트 추론
  * `WEATHER_API_KEY` (또는 `OPENWEATHER_API_KEY`): 현재 날씨 및 5일(3시간 단위) 예보 조회
* [`requirements.txt`](../requirements.txt) / [`pyproject.toml`](../pyproject.toml) : 파이썬 패키지 의존성 정의

### 2) 백엔드 핵심 소스코드 (`app/backend/`)
* [`app/backend/main.py`](../app/backend/main.py) : FastAPI 앱 진입점 및 5단계 API 라우터
* [`app/backend/engines/_01_personal_color.py`](../app/backend/engines/_01_personal_color.py) : 퍼스널 컬러 엔진
* [`app/backend/engines/_02_body_vision.py`](../app/backend/engines/_02_body_vision.py) : 3D 체형 분석 엔진
* [`app/backend/engines/_03_llm_core.py`](../app/backend/engines/_03_llm_core.py) : GPT-4o 스타일리스트 추론 및 프롬프트 계층 구조
* [`app/backend/services/wb_service.py`](../app/backend/services/wb_service.py) : A4 화이트밸런스 캘리브레이션
* [`app/backend/services/color_service.py`](../app/backend/services/color_service.py) : 12계절 톤 매핑 및 Face Mesh 시각화
* [`app/backend/services/measure.py`](../app/backend/services/measure.py) : 3D Pose World Landmarks 기반 치수 산출 및 BMI 보정
* [`app/backend/services/voice_weather.py`](../app/backend/services/voice_weather.py) : 날씨 API 타겟팅 및 Whisper 음성 인식
* [`app/backend/workflow_api.json`](../app/backend/workflow_api.json) : ComfyUI 가상 피팅 워크플로우 API 템플릿

### 3) 프론트엔드 핵심 소스코드 (`app/frontend/`)
* [`app/frontend/app.py`](../app/frontend/app.py) : 5단계 스텝퍼 반응형 웹 UI (Streamlit)

### 4) 데이터베이스 및 벡터 인덱스
* `data/AI_Style_Director.index` : 768차원 SigLIP 상품 벡터가 인덱싱된 FAISS 바이너리 파일
* `data/json/260416_AI_Style_Director_Master_DB_Meta.json` : 무신사 의류 메타데이터 (가격, 실측 사이즈표, 상품명, 무신사 링크)
* `data/images/` : 정적 이미지 서빙용 크롤링 사진 디렉토리 (FastAPI `/static` 경로에 마운트)

## 5. 시스템 구동 및 모바일 연동 절차

### 1단계: 패키지 설치
```powershell
uv sync
# 또는
pip install -r requirements.txt
```

### 2단계: 백엔드 서버 실행
```powershell
uvicorn app.backend.main:app --host 0.0.0.0 --port 8001 --reload
```
* **Swagger API 문서**: `http://localhost:8001/docs`

### 3단계: 프론트엔드 실행
```powershell
streamlit run app/frontend/app.py --server.port 8501
```
* **웹 인터페이스**: `http://localhost:8501`

### 4단계: 가상 피팅 ComfyUI 실행 (선택 사항)
* ComfyUI 설치 디렉토리에서 서버를 실행합니다 (`http://127.0.0.1:8188`).
* 백엔드의 `workflow_api.json` 노드 ID와 ComfyUI Input 디렉토리 경로가 일치하는지 확인합니다.

### 5단계: 모바일 환경 테스트 (카메라 WebRTC 구동 시 필수)
모바일 브라우저의 카메라 권한 보안 정책상 **HTTPS 환경이 필수**입니다.
```powershell
# 프론트엔드 포트 터널링
ngrok http 8501
```
1. 발급된 `https://<random-id>.ngrok-free.app` 주소로 스마트폰에서 접속합니다.
2. 백엔드 주소(`API_BASE`)를 모바일 기기가 접근할 수 있는 노트북의 Wi-Fi 로컬 IP(`http://192.168.x.x:8001`) 또는 별도 ngrok 백엔드 주소로 지정합니다.
