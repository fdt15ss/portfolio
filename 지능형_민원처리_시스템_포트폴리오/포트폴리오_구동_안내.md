## 1. 웹 포트폴리오 (`포트폴리오.html`) 단독 열람 가이드

`포트폴리오.html`은 단일 파일 기반의 인터랙티브 웹 포트폴리오입니다. 별도의 웹 서버나 백엔드 구동 없이도 브라우저에서 바로 열어 확인하실 수 있습니다.

### 1) 구동 방법
- **일반 열람**: 프로젝트 루트 디렉토리에 위치한 `포트폴리오.html` 파일을 웹 브라우저(Chrome, Edge, Safari, Firefox 등)로 더블 클릭하여 실행합니다.
- **로컬 웹 서버로 열기 (선택 사항)**:
  ```bash
  # Python 내장 HTTP 서버 구동
  python -m http.server 3000
  # 브라우저에서 http://localhost:3000/포트폴리오.html 접속
  ```

### 2) 참조 로컬 리소스
웹 포트폴리오가 정상적으로 이미지를 표시하기 위해 아래 파일들이 동일 상대 경로에 위치해야 합니다:
- `포트폴리오.html` (포트폴리오 메인 페이지)
- `efficiNetB4/gradcam_result.png` (XAI 섹션 실제 Grad-CAM 히트맵 이미지)
- `test_data/전입신고서333.jpg` (샘플 서식 테스트 이미지)

### 3) 네트워크 요구사항
- 페이지 내 차트(Chart.js), 수식 렌더링(KaTeX), 아이콘(FontAwesome), 웹폰트(Pretendard)는 CDN을 통해 로드되므로 **인터넷 연결**이 필요합니다.

### 4) PDF 변환 및 인쇄 팁
- 우측 상단의 **인쇄 버튼(프린터 아이콘)**을 클릭하거나 브라우저의 `Ctrl + P` (Mac: `Cmd + P`)를 누르면 `@media print` 스타일이 자동 적용되어 불필요한 UI(네비게이션, 테마 버튼, 진행바)가 숨겨진 깔끔한 PDF 포트폴리오로 저장할 수 있습니다.

## 3. 환경 설정 및 의존성 설치

Python 3.10 이상 환경(가상환경 권장)에서 실행합니다.

```bash
# 1. 가상환경 생성 및 활성화 (Windows PowerShell 기준)
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# (Linux / macOS)
# source .venv/bin/activate

# 2. 필수 라이브러리 설치
pip install -r requirements.txt
```

> **주요 의존성:** `torch`, `torchvision`, `transformers`, `fastapi`, `uvicorn`, `streamlit`, `pandas`, `numpy`, `pillow`, `pytorch-grad-cam`, `openai-whisper`

## 4. 단계별 서버 구동 절차

FastAPI 백엔드 서버를 먼저 띄운 후, Streamlit 프론트엔드를 실행합니다.

### 1단계: FastAPI 백엔드 추론 서버 실행
FastAPI 서버가 기동되면서 `lifespan` 이벤트에 의해 5대 딥러닝 모델이 메모리에 한 번에 로드됩니다.

```bash
# 프로젝트 루트 디렉토리에서 실행
uvicorn backend.fastapi_main:app --host 0.0.0.0 --port 8000 --reload
```
*정상 구동 시 콘솔에 아래와 같이 모델 로드 확인 로그가 출력됩니다:*
```text
========== 서버 시작: 모델 로드 ==============
필드 분석 모델 로드 중...
  - EfficientNet-B4... ✓
  - ConvNeXt... ✓
  - ResNet50... ✓
텍스트 분류 모델(ROBERTA) 로드 중... ✓
문서 분류 모델(ConvNeXt) 로드 중... ✓
========== 모델 로드 완료 ==============
```

### 2단계: Streamlit 프론트엔드 대시보드 실행
새 터미널 창을 열고(가상환경 활성화 후) Streamlit을 구동합니다.

```bash
# 프로젝트 루트 디렉토리에서 실행
streamlit run streamlit/streamlit_main.py --server.port 8501
```

### 3단계: 음성 파일 전사 (STT 테스트 시)
음성 민원 전사 기능을 단독 테스트할 경우 아래 명령어를 사용합니다:

```bash
python stt/whisper_main.py Leejamsample.mp3
# -> sttout/Leejamsample.txt 에 전사 결과 자동 저장
```

## 6. 문제 해결 및 FAQ

### Q1. FastAPI 서버 시작 시 모델 파일이 없다는 오류가 발생합니다.
- `best_model/` 디렉토리에 학습된 체크포인트 파일(`.pt`, `.pth`)들이 올바르게 위치해 있는지 확인하세요.
- 만약 가중치 파일명이 다르다면 `backend/fastapi_main.py` 상단의 파일 경로 변수(`MODEL_DIR`)를 점검합니다.

### Q2. 포트 충돌이 발생하는 경우 (8000번 또는 8501번)
- 다른 프로세스가 포트를 점유 중인 경우 다른 포트로 변경하여 실행합니다:
  ```bash
  uvicorn backend.fastapi_main:app --port 7394
  # backend 포트를 변경한 경우 streamlit/streamlit_main.py의 API_BASE_URL을 http://localhost:7394로 수정해야 합니다.
  ```

### Q3. CUDA / GPU가 없는 환경에서도 실행 가능한가요?
- 네, `backend/fastapi_main.py` 내부에서 `torch.device("cuda" if torch.cuda.is_available() else "cpu")`로 자동 분기 처리되어 있어 CPU 환경에서도 문제없이 추론이 구동됩니다.
