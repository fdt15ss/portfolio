## 🌐 2. 포트폴리오(`포트폴리오.html`) 구동 방법

포트폴리오 웹사이트는 **별도의 파이썬 커널이나 서버 실행 없이 단독으로 구동**됩니다.

### 방법 1: 파일 더블클릭 (가장 간편 · 권장)
1. 파일 탐색기에서 이 가이드가 들어 있는 `의정이슈레이더_포트폴리오` 폴더로 이동합니다. (`figure/`, `assets/slides/`, `assets/dashboard/` 폴더가 `포트폴리오.html`과 같은 위치에 있어야 이미지가 보입니다.)
2. **`포트폴리오.html`** 파일을 더블클릭합니다.
3. 기본 웹 브라우저(Chrome, Edge, Whale 등)에서 즉시 실행되며, 모든 인터랙티브 차트(Chart.js)와 이미지 확대 모달이 정상 작동합니다.

### 방법 2: 파이썬 로컬 웹서버 구동 (선택 사항)
```bash
cd 의정이슈레이더_포트폴리오
python -m http.server 8080
# → 브라우저에서 http://127.0.0.1:8080/포트폴리오.html 접속
```

### 방법 3: 주피터 노트북 내에서 열람 (선택 사항)
- `notebooks/00_view_portfolio.ipynb` 노트북을 열고 실행하면 주피터 노트북 화면 내부에서 `포트폴리오.html`을 인라인으로 열람할 수 있습니다.

## 🚀 3. 전체 시스템 최종 실행 가이드 (`07_council_issue_radar.ipynb`)

포트폴리오에서 설명하는 **의정이슈레이더 전체 시스템(90만 청크 검색, 포아송 회귀 예측, 로컬 LLM 에이전트, 인터랙티브 웹 대시보드)**을 직접 구동하고 재현할 때의 실행 절차입니다:

### 3.1 실행 절차 (원클릭 Run All)
```bash
# 1) Conda 가상환경 활성화
conda activate council-radar

# 2) 주피터 랩 실행
jupyter lab notebooks
```
3. 주피터 랩 화면에서 **`07_council_issue_radar.ipynb`**를 엽니다.
4. 상단 메뉴에서 **[Kernel] → [Restart Kernel and Run All Cells]**를 클릭합니다.

### 3.2 노트북 07의 자율 오케스트레이션 단계
- **1-1 셀 (자동 환경 점검 및 준비):** `.env` 생성, 모델 다운로드, Docker Desktop에서 `pgvector` 컨테이너 시작 및 사전 제출된 덤프 파일(`data/db/council_vectors.dump`, 901,358건) 자동 복원.
- **2 셀 (로컬 LLM 확인):** Ollama 상태 점검 및 `A.X-4.0-Light` 모델 확인.
- **3~5 섹션 (검색 엔진 가동):** DB 테이블 검증, 질의 임베딩 모델 로드, pgvector 의미 검색 + PostgreSQL 전문검색을 RRF로 합치는 하이브리드 검색 함수 정의. 전문검색용 GIN 색인이 없으면 검색이 느리므로, `CREATE_FTS_INDEX = True`로 한 번 만들 수 있습니다(DB 변경).
- **6~8 섹션 (외부 데이터 & 예측):** 10개 대표 이슈 로드, 법제처·국회·KOSIS 공공데이터 조회(키가 없으면 건너뜀), 이슈 구성 청크 군집화, 포아송 회귀 학습 및 다음 달 언급량 예측.
- **9~11 섹션 (분석 & 설명):** 의회별 최초 관측 시점·순서 계산(인과관계 아님), 후속 논의 흐름 보고서 작성, `[근거 N]` 인용 기반 로컬 LLM 질의응답.
- **12 섹션 (서버 & 대시보드):** 백그라운드 스레드로 FastAPI 서버를 띄우고 `src/dashboard`를 함께 제공합니다. 셀에 출력된 **`http://127.0.0.1:8000`** 링크를 누르면 대시보드가 열립니다(포트가 사용 중이면 다음 빈 포트를 씁니다).

    "assets/dashboard/dash_05_search.png",

foreach ($f in $files) {

*(모든 항목이 `[정상]`으로 출력되면 포트폴리오를 완벽하게 열람하실 수 있습니다.)*
