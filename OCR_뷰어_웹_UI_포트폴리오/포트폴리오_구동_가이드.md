# 포트폴리오 열람 및 프로젝트 실행 가이드

이 문서는 두 가지를 안내합니다.

1. [포트폴리오.html](포트폴리오.html)을 여는 방법
2. 웹 OCR 뷰어(Vue.js 프론트엔드)를 로컬에서 실행하고, 배포용 파일을 만드는 방법

---

## 1. 포트폴리오 열기

`포트폴리오.html`은 HTML·CSS·JS가 파일 하나에 모두 들어 있어 별도 설치 없이 열 수 있습니다.

### 방법 1: 브라우저로 바로 열기 (가장 간단)

- 파일 탐색기에서 `포트폴리오.html`을 더블클릭하거나, 브라우저 창에 끌어다 놓습니다.

### 방법 2: VS Code Live Server

- VS Code 탐색기에서 `포트폴리오.html`을 마우스 오른쪽 클릭 → **Open with Live Server**를 누릅니다.

### 방법 3: 로컬 HTTP 서버

포트폴리오 폴더(`OCR_뷰어_웹_UI_포트폴리오`)에서 실행합니다.

```powershell
# Python이 있는 경우
python -m http.server 8000
# 브라우저에서 http://localhost:8000/포트폴리오.html 접속

# Node.js가 있는 경우
npx serve .
```

> **주의**: 스크린샷은 같은 폴더의 `screenshots/` 안에 있는 이미지 두 개(`WEB_ODRVIEWER__main-screen-1600x1000-masked.png`, `WEB_ODRVIEWER-2.png`)를 불러옵니다. 폴더 구조를 그대로 두고 열어야 이미지가 보입니다.

---

## 2. 프로젝트 구성

이 프로젝트는 **Vue.js 프론트엔드**와 **Spring Boot 중계 서버(백엔드)** 두 부분으로 이루어져 있습니다. 이 저장소에는 **프론트엔드만** 들어 있고, 백엔드는 별도 저장소에서 관리했습니다.

### 프론트엔드 주요 파일 (이 저장소)

| 파일 | 역할 |
| :--- | :--- |
| `package.json` | 사용하는 라이브러리 목록(Vue 2.6, pdfjs-dist 2.5.207, tiff.js, blueimp-load-image, ExifReader, panzoom, vue-resizable, xlsx 등)과 실행·빌드 명령어 |
| `vue.config.js` | 빌드 설정. `.env`의 주소로 개발 서버 프록시 연결, 빌드 결과 폴더(`dist/static`) 지정, IE11용 폴리필을 진입점에 추가, 일부 라이브러리(`exifreader`, `vue-zoomer`, `vue-resizable`)를 Babel 변환 대상에 포함 |
| `babel.config.js` | IE11 대응을 위한 Babel 설정(`useBuiltIns: 'entry'`, core-js 3) |
| `public/index.html` | 앱이 올라가는 기본 HTML |
| `src/main.js` | Vue 앱 시작, 라우터·BootstrapVue·panzoom 등 등록, IE11 폴리필 불러오기(`core-js`, `regenerator-runtime`, `intersection-observer`, `path2d-polyfill`, `css-vars-ponyfill` 등) |
| `src/router.js` | 페이지 경로 설정(`/`, `/settings`, `/about`, `/login`, `/users`), history 모드 |
| `src/views/Home.vue` | 메인 뷰어 화면: 3단 영역(이미지 목록·문서 뷰어·결과 편집), 파일 불러오기(PDF·TIFF 포함), 인식 영역 그리기, 회전, 확대 미리보기, Excel·JSON 저장 |
| `src/views/Settings.vue` | 설정 화면: OCR 서버 목록 관리, 동시 요청 수 조절, Agent 업데이트 파일 업로드 |
| `src/axios/api.js` | 동시에 보내는 OCR 요청 수를 제한하는 axios 인터셉터 |
| `src/ocr/ServerRequest.js` | 백엔드 API 호출 모음(`/ocr`, `/odr`, `/info`, `/get-config`, `/save-config`, `/get-concurrency`) |
| `src/ocr/clickAreaProcess.js`, `src/odr/odrClickAreaProcess.js` | 클릭한 점이 어느 인식 영역(다각형) 안에 있는지 판별(Ray casting) |
| `src/ocr/rotate.js`, `src/odr/odrRotate.js` | 90°/180°/270° 회전 시 이미지와 인식 영역 좌표 계산 |
| `src/odr/crop.js` | 확대 미리보기를 위해 영역의 좌우·위아래 끝 좌표 계산 |

### 백엔드 (별도 저장소)

프론트엔드가 호출하는 API를 제공하는 Spring Boot 서버입니다. 주요 역할은 다음과 같습니다.

- 브라우저 대신 OCR 서버(Agent)에 요청을 전달해 CORS 문제 해결 (RestController + WebClient)
- 서버 목록, 선택한 서버, 동시 요청 수 등 설정을 CSV 파일로 저장·불러오기
- WAS 배포를 위한 WAR 빌드

> 프론트엔드는 실행될 때 백엔드의 `/get-concurrency`로 동시 요청 수를 받아옵니다. 백엔드가 응답하지 않으면 브라우저 세션마다 안내창을 한 번 띄우고 기본값 3으로 동작합니다.

## 3. 실행 및 배포 절차

### 준비물

- Node.js, npm
- (권장) VS Code

> `package.json`의 실행 명령어에 `NODE_OPTIONS=--openssl-legacy-provider`가 들어 있어, Node.js 17 이상에서도 Vue CLI 4(webpack 4)로 빌드할 수 있습니다.

### 1단계: 패키지 설치 및 개발 서버 실행

프로젝트 최상위 폴더(`package.json`이 있는 곳)에서 실행합니다.

```powershell
# 1. 패키지 설치 (처음 한 번, 또는 package.json이 바뀌었을 때)
npm install

# 2. 개발 서버 실행 (8021 포트)
npm run serve
```

- 터미널에 `DONE  Compiled successfully`가 나오면 브라우저에서 `http://localhost:8021`로 접속합니다.

### 2단계: 백엔드 주소 연결

프로젝트 최상위 폴더에 `.env` 파일(또는 `.env.local`)을 만들고, 요청을 보낼 서버 주소를 적습니다. 개발 서버는 이 주소로 API 요청을 프록시합니다.

```env
# 예) 백엔드가 http://localhost:8022 에서 실행 중인 경우
OCRDOMAIN=http://localhost
OCRPORT=8022
```

- 백엔드 없이 OCR Agent에 바로 요청하고 싶다면 `OCRDOMAIN`, `OCRPORT`를 Agent 주소로 맞춥니다.
- `.env` 파일은 `.gitignore`에 포함되어 있어 저장소에 올라가지 않습니다.

### 3단계: 배포용 파일 만들기

1. **프론트엔드 빌드**

   ```powershell
   npm run build
   ```

   - `dist/static` 폴더에 배포용 정적 파일이 만들어집니다. PDF.js Worker와 폴리필이 모두 번들에 포함되어 외부 CDN 없이 동작합니다.

2. **백엔드와 함께 배포**

   - 빌드된 `dist/static`의 파일을 백엔드 프로젝트에 넣고, 백엔드를 WAR로 빌드해 WAS에 배포합니다.
   - 백엔드 빌드 명령어는 백엔드 저장소의 빌드 도구(Maven 또는 Gradle) 설정을 따릅니다.

### 기타 명령어

```powershell
# 코드 검사(ESLint)
npm run lint
```
