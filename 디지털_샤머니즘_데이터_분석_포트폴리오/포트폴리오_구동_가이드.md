## 🚀 2. 포트폴리오 실행 방법

### 방법 A. 가장 간편한 로컬 더블 클릭 (권장)
1. 파일 탐색기에서 `디지털_샤머니즘_데이터_분석_포트폴리오` 폴더로 이동합니다.
2. **`포트폴리오.html`** 파일을 더블 클릭합니다.
3. 기본 웹 브라우저(Google Chrome, Microsoft Edge, Safari, Firefox, Whale 등)에서 즉시 열립니다.

### 방법 B. 로컬 웹 서버를 통한 실행
보안 정책상 로컬 파일(`file://`) 프로토콜에서 일부 스크립트 실행이 제한되는 사내 PC 환경인 경우, 파이썬 내장 웹 서버를 이용할 수 있습니다:
```bash
# 포트폴리오 폴더(포트폴리오.html이 있는 위치)에서 실행
python -m http.server 8000
```
브라우저 주소창에 `http://localhost:8000/포트폴리오.html`을 입력하여 접속합니다.

## 🌐 3. 외부 네트워크 (CDN) 의존성 안내

`포트폴리오.html`은 별도의 로컬 패키지 설치 없이 최신 웹 기능을 제공하기 위해 아래의 검증된 공용 CDN(Content Delivery Network) 라이브러리를 사용합니다. 따라서 **초기 로딩 시 인터넷 연결이 필요**합니다:

| 라이브러리 | 사용 목적 | 호스팅 출처 |
| :--- | :--- | :--- |
| **Tailwind CSS 3** | 모던 반응형 레이아웃, 다크 모드, 글래스모피즘 디자인 | `cdn.tailwindcss.com` |
| **Chart.js** | 별점 도넛 차트, 60개월 검색 추이 라인 차트 (4.4.1 고정) | `cdn.jsdelivr.net` |
| **Font Awesome 6** | 벡터 아이콘 표시 | `cdnjs.cloudflare.com` |
| **Pretendard & Inter** | 고품질 한글/영문 웹 폰트 | `cdn.jsdelivr.net`, `fonts.googleapis.com` |

## 💡 4. 인터랙티브 기능 및 브라우저 UX 활용 팁

1. **인터랙티브 차트 (Chart.js)**:
   - **별점 분포 도넛 차트**: 각 부채꼴 영역에 마우스를 올리면 실제 건수(건)와 비율(%)이 툴팁으로 표시됩니다. 범례 항목을 클릭하여 특정 별점을 숨기거나 표시할 수 있습니다.
   - **60개월 검색 추이 라인 차트**: 실제 네이버 데이터랩 값이며, 마우스를 올리면 월별 상대지수를 확인할 수 있습니다. 큰 점은 1월 값, 빨간 점은 최고치(2024년 7월)입니다.
2. **워드클라우드 다차원 비교 탭**:
   - `긍정 (4~5점)`, `5점`, `비긍정 (1~3점)`, `1점`, `카페 고민글` 탭 버튼을 클릭하여 그룹별 자주 나온 단어를 비교할 수 있습니다.
3. **고해상도 이미지 라이트박스 (Lightbox Modal)**:
   - 페이지에 삽입된 그래프나 워드클라우드 카드를 클릭하면 **전체 화면 라이트박스 모달**이 열려 원본 고해상도로 확대 관찰할 수 있습니다. (`ESC` 키 또는 바깥 영역 클릭 시 닫힘)
4. **다크 모드 / 라이트 모드 전환**:
   - 우측 상단의 해/달 아이콘 버튼으로 전환할 수 있으며, 선택한 모드는 브라우저에 기억됩니다.
5. **A4 최적화 PDF 저장 및 인쇄**:
   - 우측 상단의 **'PDF 출력'** 버튼을 클릭하거나 브라우저에서 `Ctrl + P` (Mac: `Cmd + P`)를 누르면, 상단 메뉴와 버튼이 숨겨지고 자동으로 밝은 화면으로 바뀌며, 워드클라우드 탭 5개가 모두 펼쳐진 상태로 PDF에 저장됩니다.

## 📦 5. 외부 제출 및 타 PC 전달 시 패키징(배포) 방법

채용 담당자, 평가 위원회, 또는 외부 동료에게 이메일이나 메신저로 포트폴리오를 제출할 때는 다음 두 요소를 함께 전달해야 합니다:

1. **압축 대상**:
   - `포트폴리오.html` (파일)
   - `output/portfolio_screenshots/` (디렉토리 전체)
   - `포트폴리오_구동_가이드.md` (선택 사항)
2. **배포 팁**:
   - 위 항목들을 하나의 **`.zip` 파일**로 압축하여 전달합니다.
   - 수신자가 압축을 풀고 `포트폴리오.html`을 실행하면 어느 PC에서나 모든 이미지와 차트가 정상적으로 렌더링됩니다.

## 🔬 6. (참고) 원천 프로젝트 분석 환경 구동 가이드

포트폴리오의 근간이 된 데이터 수집, 형태소 분석, 연관 규칙 분석 노트북(프로젝트 루트 폴더에 있음)을 직접 실행해보고자 할 경우의 환경 설정 안내입니다.

### 1) 파이썬 가상환경 구성
본 프로젝트는 Python 3.11+ 기반으로 구축되었습니다:
```bash
# uv를 사용하는 경우 (권장)
uv sync

# 또는 venv + pip 사용 시
python -m venv .venv
source .venv/Scripts/activate  # Windows: .venv\Scripts\activate
pip install -e .
```

### 2) 핵심 의존 패키지
* 웹 스크래핑: `selenium>=4.40.0`, `beautifulsoup4`, `google-play-scraper`
* 데이터 처리: `pandas`, `numpy`, `openpyxl`
* 자연어 처리: `konlpy`, `kiwipiepy`, `emoji`
* 머신러닝 및 네트워크: `mlxtend` (Apriori), `networkx`
* 시각화: `matplotlib`, `seaborn`, `wordcloud`, `koreanize-matplotlib`

### 3) 주요 노트북 실행 순서
1. `project01_데이터_수집_Selenium.ipynb`: 네이버 사주 카페 게시글 제목 수집(55페이지, 816건) 및 제목 워드클라우드
2. `project01_playstore.ipynb`: 포스텔러 앱 리뷰 6,925건 수집, 명사 추출, Apriori 연관 규칙, NetworkX 단어 연결망
3. `project01_데이터랩.ipynb`: 네이버 데이터랩 '사주·운세·타로' 60개월 추이 그래프
4. `[프로젝트] 1조_데이터_트렌드_분석.ipynb`: 네이버·구글 키워드별 월간 지수 병합 및 36개월 추이 그래프
